# backend（C++20 后端预留目录）

本目录为后续 C++20 后端预留，目前**尚未开始实现**，不影响现有前端运行。

## 计划使用的目录结构（按需逐步创建，不提前建空目录）

```
backend/
├── CMakeLists.txt      # 顶层构建入口（CMake，C++20）
├── include/            # 对外头文件
├── src/                # 实现文件
├── tests/              # 测试代码
└── cmake/              # 自定义 CMake 模块
```

## 约定

- 语言标准固定为 C++20，构建系统使用 CMake。
- 源文件换行符为 LF（由仓库根目录 `.gitattributes` 统一约束）。
- 编译产物不进入版本库（见仓库根目录 `.gitignore` 中的 `build/`、`cmake-build-*/` 等规则）。
- 密钥、数据库口令、令牌等敏感信息一律通过环境变量或本地未跟踪文件提供，禁止提交。
- 后端目录的创建与改动在 `dev` 分支进行，通过 Ubuntu 环境编译与验收后再合并到 `main`。
